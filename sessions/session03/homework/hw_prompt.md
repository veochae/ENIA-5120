# Homework 01 – Data Description & Cleaning Foundations

Using the Laser League player log, submit a 1–2 page brief plus an R script that:

1. Describes the dataset structure (variables, types, sample size) and highlights at least three quality issues.
2. Shows exploratory summaries (`summary()`, `str()`, custom tables) and missing-value checks.
3. Demonstrates a basic cleaning pipeline: renaming columns, fixing obvious types, and handling missing values with justification.

Your write-up should explain what you changed and why, and your script should be reproducible with `read_csv()` + relative paths.
