# Homework 04 – Predictive Modeling & Interpretation

Deliver a 3–4 page modeling report (plus R script) that:

1. Specifies at least one linear model (e.g., predicting season_score) and one logistic model (e.g., high_glow flag) with thoughtful feature choices.
2. Interprets key coefficients in plain language and comments on significance.
3. Includes diagnostics (residual plots) for the linear model and a confusion matrix or ROC/AUC for the logistic model.
4. Compares the models or variants, explains performance metrics (MAE/RMSE, accuracy/recall, etc.), and notes limitations.
