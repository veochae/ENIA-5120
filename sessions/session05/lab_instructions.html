2. Violin: Shape Across Groups 🆕

The histogram showed two humps. The question is which stations make up the second hump. To answer that, you need to see the shape of each group side by side.

A violin is a density curve (Lab 4) turned on its side and mirrored, so it looks like a violin. One violin per group. Where it's wide, lots of values sit there. Where it's thin, few do.

ggplot(pets, aes(x = species, y = weight_kg, fill = species)) +
  geom_violin()
Analogy: A boxplot tells you where the middle of the crowd is. A violin shows you the crowd itself, including where people bunch up in two separate groups.

Sorting groups: by default, R puts groups in alphabetical order, which rarely means anything. reorder(energy_source, temp_c, FUN = median) sorts them by their median temperature instead, so the chart reads from coolest to hottest.

✨ The polish checklist. From this section on, every chart you make should have:
  • A title that states the takeaway ("Solar stations run far hotter"), not just the variable names
  • Axis labels with units ("Temperature (°C)", not temp_c)
  • A sensible order (reorder()) instead of alphabetical
  • Colorblind-safe colors. scale_fill_viridis_d() is built in. The _d is for discrete (categories). Add guide = "none" to hide a legend that just repeats the x-axis.
  • theme_minimal() for a clean background
HW1 grades whether your charts are "clear, labeled, and readable." This checklist is how you get those points.

3. Ridgeline: Same Question, Another View 🆕

A ridgeline stacks one density curve per group, like a mountain range seen from the side. It answers the same question as the violin, but the shapes are easier to compare because they share one x-axis.

ggplot(pets, aes(x = weight_kg, y = species, fill = species)) +
  geom_density_ridges()
The axes swap. In a violin, the groups go on x and the numbers go on y. In a ridgeline it's the opposite: numbers on x, groups on y. If you mix them up, R won't give an error. It just draws a strange chart, so double-check which is which.

R may print a message like "Picking joint bandwidth of 1.6." That's not an error. It's just telling you how smooth it made the curves.

4. Rare Groups: Fix the Bar Chart (✅ then 🆕)

4.1 is a sorted bar chart, same as Lab 3. Three programs each hold only about 6% of grants. From lecture, you have four options: combine, lump into "Other," keep and flag, or drop.

In 4.2 you'll combine with case_when(), which you know from Lab 2. The new part isn't the code. It's the decision: which groups actually belong together?

pets %>%
  mutate(pet_group = case_when(
    species %in% c("Hamster", "Gerbil", "Mouse") ~ "Small rodents",
    TRUE ~ species
  ))

The last line, TRUE ~ species, means "everything else keeps its original name."

Combine by meaning, not by size. Drought, Heat, and Wildfire all deal with hot, dry conditions, so they make a real group. Clean Energy Transition is small too, but it's about cutting emissions, not surviving extreme weather. Lumping it in just because it's small would make the new group meaningless.

5. Scatterplot, Trend Line, and r 🆕

The one relationship type you haven't charted yet: number vs. number. Every row becomes one dot, placed by its two values.

ggplot(pets, aes(x = age_years, y = weight_kg)) +
  geom_point(alpha = 0.3) +
  geom_smooth(method = "lm", se = FALSE)

cor(pets$age_years, pets$weight_kg)
  • alpha = 0.3 makes each dot 70% see-through. With 840 dots, they overlap, and see-through dots let crowded areas show up darker.
  • geom_smooth(method = "lm") draws the straight line that best fits the cloud. "lm" stands for linear model. That's next week's topic, so remember this line. se = FALSE hides the gray band around it for now.
  • cor() gives you r, the single number from lecture: sign for direction, size for strength.
Reading it, in order: direction (up or down?), strength (tight or loose cloud?), form (straight or curved?), oddballs (anyone far from the crowd?). Same four questions every time.

6. Box Plus Dots (✅ then 🆕)

6.1 is a boxplot per group, same as Lab 4. In 6.2 you add one layer on top: geom_jitter(), which draws every single data point, nudged a little sideways so they don't stack into one line.

ggplot(pets, aes(x = species, y = weight_kg)) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.2, alpha = 0.3)
Why outlier.shape = NA? A boxplot draws its own dots for outliers. The jitter layer already draws every dot, outliers included, so without this you'd see some points twice.

Remember the "dots on a category" chart from the slides that looked like stripes? Jitter is the fix: spreading the dots out makes the crowd visible.

7. Category vs. Category: Count Heatmap 🆕

In Lab 4 you compared two categories with a 100% stacked bar. A count heatmap is another way: a grid where each square is one combination, colored by how many rows fall into it.

pets %>%
  count(species, size) %>%
  ggplot(aes(x = size, y = species, fill = n)) +
  geom_tile() +
  geom_text(aes(label = n))

geom_tile() draws the squares, and geom_text() writes the count on each one, so nobody has to guess numbers from colors. Use scale_fill_viridis_c() for the colors. The _c is for continuous (numbers).

8. Change Over Time (✅ then 🆕 🆕)

8.1 is a line chart of average CO₂ by year, like Lab 2. Then you turn it into a story in two ways.

8.2 Annotate. annotate() writes your own text anywhere on the chart. You tell it where with x and y, using the chart's own units (years and ppm here).

annotate("text", x = 2016, y = 417, hjust = 0,
         label = paste0("+", round(co2_rise, 1), " ppm in 6 years"))

hjust = 0 makes the text start at that point instead of centering on it. paste0() glues text and numbers into one label, so the number updates itself if the data changes.

8.3 Highlight. An average line hides everyone. Drawing all 120 stations at once is a mess. The trick: draw everyone in light gray, then draw the one you care about on top in a bold color.

ggplot(pets_by_year, aes(x = year, y = weight_kg, group = pet_name)) +
  geom_line(color = "grey85") +
  geom_line(data = rex_only, color = "orange", linewidth = 1.5)
  • group = location tells R to draw one separate line per station. Without it, R tries to connect all 840 points into a single zigzag.
  • The second geom_line() brings its own data (only Lakevale's rows), so it draws on top of the gray layer.
Analogy: Highlighting is a spotlight on a dark stage. Everyone is still there, but the audience knows exactly where to look.

9. The 3°C Mystery (🆕 then ✅)

Lab 4 found that funded station-years were about 3°C cooler. Do grants cool towns down? Time to find out.

9.1 takes your Section 5 scatterplot and colors every dot by funded. Adding color = inside aes() is how you bring a third variable into a two-variable chart.

ggplot(pets, aes(x = age_years, y = weight_kg, color = indoor)) +
  geom_point() +
  scale_color_manual(values = c("Yes" = "teal", "No" = "orange"))
fill vs. color. Shapes with an inside (bars, boxes, violins, tiles) use fill. Dots and lines use color. If your colors don't show up, you probably used the wrong one.

9.2 is already written. It splits every station-year into a Dry, Medium, or Wet rain band, then compares funded vs. not funded inside each band. If rain is the real reason for the gap, the gap should shrink once you only compare places with similar rain.

Analogy: Umbrella owners get wet more often than people without umbrellas. Do umbrellas cause rain-soaked clothes? No. People who own umbrellas live in rainy places. Compare umbrella owners and non-owners in the same city, and the difference disappears.

10. The Hydro Flip 🆕

Section 5 showed one trend line for all 840 station-years: rainier means cooler. But is that true for every kind of station? Copy your Section 5 chart and add one line:

  facet_wrap(~ energy_source)

You know facet_wrap() from Lab 3. Because your chart already has geom_smooth(), every panel gets its own trend line automatically.

Then put a number on it: cor() works inside summarize(), so combining it with group_by() gives you one r per energy source.

pets %>%
  group_by(species) %>%
  summarize(r = cor(age_years, weight_kg))

This is the habit from lecture: after you find a pattern, split it by a category and see if it survives.

11. Find the Twins 🆕

Hand cor() a whole table of numbers instead of two columns, and it returns r for every pair at once. That grid is called a correlation matrix.

ggplot can't draw a matrix directly, so one line reshapes it into a long table with one row per pair:

cor_long <- as.data.frame(as.table(cor_matrix))

Run it and look: you get three columns, Var1, Var2, and Freq. Despite the odd name, Freq is just the r value for that pair. Then it's the same tile chart as Section 7, with one new color scale: scale_fill_gradient2(), which uses one color for negative r, white for 0, and another for positive r.

ggpairs() (from GGally) goes one step further: a scatterplot for every pair, each variable's shape on the diagonal, and the r values in the other corner. It's a whole EDA in one picture.

What are the stars in ggpairs()? They're significance flags, same idea as p-values in Lab 4. More stars means stronger evidence the correlation isn't just luck. *** is p < 0.001.
Remember the twins rule from lecture: look for |r| above 0.7 to 0.8 between two input variables. Twins aren't wrong, but a model can't tell which one deserves the credit. Keep the one that makes more sense for your question.

12. Bubble Chart, Then Make It Interactive 🆕

A bubble chart is a scatterplot that carries two more variables: one in the size of each dot, one in its color. Four variables, one chart.

ggplot(shelters, aes(x = staff, y = adoptions, size = dogs, color = region)) +
  geom_point(alpha = 0.7)

Then the fun part: ggplotly() turns any ggplot into an interactive chart you can hover over, zoom into, and click legend items on and off.

To control what shows up when you hover, add a text = aesthetic built with paste0(). "<br>" starts a new line in the hover box.

chart <- ggplot(shelters, aes(x = staff, y = adoptions,
                  text = paste0(name, "<br>Dogs: ", dogs))) +
  geom_point()

ggplotly(chart, tooltip = "text")
"Ignoring unknown aesthetics: text." ggplot doesn't know what text is for, so it may warn you. That's fine: ggplot ignores it, and ggplotly() picks it up. tooltip = "text" tells plotly to show only your label instead of every raw value.
Interactive charts only work in HTML. If you knit to PDF, plotly charts won't appear. For HW1, knit to HTML if you use them.

13. The Interactive Map 🆕

A map is just a scatterplot where x is longitude (east-west) and y is latitude (north-south). Two new layers make it look like a map:

  • borders("state") draws the US state outlines (from the maps package).
  • coord_fixed(1.3) locks the shape, so the country doesn't get squished when the chart resizes.
ggplot() +
  borders("state", fill = "grey95", colour = "grey70") +
  geom_point(data = shelters, aes(x = longitude, y = latitude, color = dogs)) +
  coord_fixed(1.3) +
  theme_void()
Why is data = inside geom_point()? The state outlines and the stations come from two different sources. So ggplot() starts empty, borders() brings its own outlines, and geom_point() brings towns. Each layer carries its own data.

Then wrap it in ggplotly(..., tooltip = "text"), same as Section 12. The tooltip = "text" part matters even more here. Without it, hovering over a state shows meaningless outline numbers.

Want a fancier map someday? The leaflet package draws real street-map tiles you can zoom into, like Google Maps. It uses a different syntax, so it's not part of today, but it's worth a look for your final project.

14. Save Your Favorite 🆕

ggsave() saves a chart as an image file you can drop into slides or a report. The file lands in the same folder as your worksheet.

ggsave("my_chart.png", chart, width = 8, height = 5)

It saves the regular ggplot version, not the interactive one. That's why you saved your charts with names like bubble instead of only printing them.
