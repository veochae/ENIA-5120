# Lab 04 – Proving the Pattern

## Goals
- Visualize distribution shape and explain why CLT supports inference
- Compute and interpret z-scores
- Use t-tests and ANOVA to compare group means
- Use chi-square tests to assess relationships between categorical variables

## Tasks
1. Load `wa_ev_population.csv` and `wa_ev_charge_stations.csv`, and clean `station_group` and `zip`.
2. Plot the distribution of `electric_range` and explain skew + CLT.
3. Compute a z-score for a station with 15 Level 2 ports and interpret it.
4. Run a t-test comparing BEV vs PHEV electric range and interpret p-value + CI.
5. Run an ANOVA comparing Level 2 ports across station groups and interpret the F test.
6. Run a chi-square test for EV type vs county (top 3 counties) and interpret the result.
